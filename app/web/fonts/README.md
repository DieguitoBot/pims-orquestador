# Tipografías del panel

Fuentes de distribución abierta, alojadas en el propio proyecto:

- **Newsreader**, títulos: https://github.com/google/fonts/tree/main/ofl/newsreader
- **Public Sans**, interfaz: https://github.com/google/fonts/tree/main/ofl/publicsans

Ambas incluyen sus licencias SIL Open Font License 1.1 en esta carpeta.
Los WOFF2 son subconjuntos latinos de sus archivos variables, incluidos acentos
y signos españoles. No se consulta Google Fonts ni otro CDN al abrir el panel.
Se conserva la tipografía de sistema como respaldo mientras carga la fuente.
